title: Поддержка клавиш
---

Платформа поддерживает все клавиши, включая:

-  Функциональные клавиши: `F1`–`F12`

-  Цифры и буквы: `Digit0`–`Digit9`, `KeyA`–`KeyZ`

-  Специальные символы: `Backquote`, `Minus`, `Equal`, `Backslash`, `Backspace`

-  Навигационные клавиши:

   -  `Tab`, `Enter`, `Escape`, `Delete`, `Insert`

   -  `Home`, `End`, `PageUp`, `PageDown`

   -  `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`

#### **Как использовать это в тест-кейсах:**

1. **Для прокрутки страницы**

   -  Клавиша `PageDown` для скроллинга страницы вниз.

   -  Клавиша `PageUp` для скроллинга страницы вверх.

2. **Для навигации по интерфейсу**

   -  Стрелки (`ArrowUp`, `ArrowDown`) позволяют перемещать каретку по редактируемому тексту.

   -  `Enter` -- для подтверждения действий (например, отправка поискового запроса).

#### **Почему это важно**

-  Позволяет тестировать интерактивные элементы (например, слайдеры, игры, формы с горячими клавишами). 

-  Упрощает навигацию без привязки к конкретным локаторам.

-  Повышает стабильность тестов за счет имитации реальных действий пользователя.
