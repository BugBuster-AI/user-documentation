---

Раздел описывает, как использовать шаги **API request** при создании тест‑кейсов: для подготовки данных, проверки ответов сервисов и передачи данных между шагами.

## Что вы узнаете

- Что такое шаг API request и в каких сценариях он полезен
- Как с его помощью получать и подготавливать данные перед UI‑шагами
- Как проверять ответы внешних сервисов из тест‑кейса
- Как сохранять данные из ответа и использовать их в следующих шагах

## Для кого этот раздел

Раздел будет полезен:
- QA‑инженерам, которые создают и поддерживают автоматизированные тесты
- Тестировщикам, которым нужно сочетать UI‑и API‑проверки в одном сценарии
- Командам, которые хотят ускорить тесты за счёт части логики «через API»
