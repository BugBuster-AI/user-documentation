---

Раздел содержит подробное руководство по созданию тест-кейсов: от написания шагов на естественном языке до использования продвинутых возможностей уточнения элементов и переиспользования шагов.

## Что вы узнаете

- Как писать шаги тест-кейсов на естественном языке
- Как работает валидация шагов и что делать при ошибках
- Какие действия поддерживает платформа (клики, ввод текста, API запросы)
- Как описывать элементы интерфейса для точного поиска
- Как использовать OCR для копирования текста с изображений
- Как создавать переиспользуемые наборы шагов (shared steps)
- Как работать с проверками ожидаемых результатов (expected results)
- Как уточнять элементы с помощью визуального выделения

## Для кого этот раздел

Раздел будет полезен:
- QA инженерам, создающим автоматизированные тесты
- Тестировщикам, пишущим тест-кейсы
- Разработчикам, интегрирующим тесты в процесс разработки
