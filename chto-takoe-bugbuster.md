Платформа для автоматизации тестирования на основе Vision Language Models (VLM), которая видит интерфейс как пользователь и понимает язык, близкий к обычной речи.

**Базовый стек**: VLM + Grounding + Playwright.

**Расширяемость**: поддержка любых других фреймворков.

**Roadmap**: добавление инструмента автоматизации для мобильного тестирования.

## **Особенности**

-  Не требуются навыки написания кода.

-  Тест-кейсы описываются в свободной форме.

-  Не требуется жесткое структурирование, как в Gherkin.

-  Не нужны дополнительные слои абстракции, как в Cucumber.

-  Нет необходимости:

   -  прописывать селекторы,

   -  иметь доступ к DOM структуре,

   -  поддерживать локаторы при изменениях верстки.

-  Стабильное взаимодействие с динамическими элементами через визуальное восприятие пользовательского интерфейса.

## **Целевая аудитория**

**QA-специалисты**, которые которые сталкиваются с долгим процессом автоматизации. Для быстрого создания и упрощенной поддержки автоматизированных тестов.

**Команды без выделенных ресурсов на автоматизацию**. Для внедрения автоматизированного тестирования при отсутствии QA Automation специалистов.

**Нетехнические специалисты**. Для автоматизации сценариев без знаний программирования.
