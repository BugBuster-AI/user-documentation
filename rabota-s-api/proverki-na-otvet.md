На форме расширенного редактирования доступно добавление проверок для ответа запроса.

![](./proverki-na-otvet.png){width=7680px height=4320px}

Для проверки доступны следующие сущности:

```
response.body[0].role_title2[1][1].test
response.headers.server
response.headers
response.body
response.statusCode
response.text
response.url
```
