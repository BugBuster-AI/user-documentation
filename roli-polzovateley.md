title: Роли пользователей
---

В системе предусмотрены три вида пользовательских ролей: **admin**, **member** и **read-only**.

-  **Admin** имеет полный доступ ко всем функциям. Может приглашать новых пользователей и управлять их правами.

-  **Member** может создавать и запускать тест-кейсы. Не может приглашать других пользователей.

-  **Read-only** имеет право только на просмотр данных без возможности редактирования.

Каждый зарегистрировавшийся пользователь получает роль **admin** и **Workspace** -- рабочую область для управления пользователями.

Чтобы добавить нового участника в свою рабочую область:

1. Перейдите в **Workspace**,

2. Нажмите кнопку **Invite User**,

3. Заполните форму,

4. Нажмите кнопку **Invite**.

Приглашенный пользователь будет видеть только те проекты, которые вы укажите при заполнении формы. Список всех добавленных вами пользователей с информацией об их статусе, ролях и активности доступен на вкладке **Workspace**.
